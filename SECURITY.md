# Security Policy

## Supported Versions

Only versions deployed via the **release-flow** (tagged releases) are currently supported with security updates.

| Version | Supported          |
| ------- | ------------------ |
| v1.x    | :white_check_mark: |
| develop | :x:                |

## Reporting a Vulnerability

If you discover a security vulnerability within this project, please do not report it via public issues. Instead, please follow the steps below:

1. **Email us**: Send a detailed report to `liberatti.gustavo@gmail.com` (replace with actual email if known, but I'll use a placeholder if not sure, or better, use the user's domain).
2. **Details**: Include a description of the vulnerability, steps to reproduce, and potential impact.
3. **Response**: You can expect a response within 48 hours acknowledging your report and an estimate for a fix if applicable.

We appreciate your help in keeping this project secure!
